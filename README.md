# test-automation-playwright

## Automation strategy and planning
A quick planning and arquirtecture to achive the requieremets, configuation of the CI test and local test. This repository contains a test automation suite using Playwright and TypeScript against the [The Internet Herokuapp](https://the-internet.herokuapp.com/).


## How to run the tests locally
1. **Clone the repository and navigate into it**
2. **Install dependencies:**
   bash or visual studio
   npm ci

   # Run in headless mode
   npx playwright test

   # Run in UI mode (interactive)
   npx playwright test --ui
